A tiny Node 22 program for the make.fun bounty
[One Line, One Minute: The Funniest AI Excuse](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18).

`main.ts` writes one excuse to `/output/entry.txt`: the agent apologises
for missing the deadline because it delegated the deadline to a sub-agent,
who delegated it to another sub-agent, who is still reading the brief.
The joke turns the agent's own habit — spawning sub-agents — into the
dodge, and the twist lands on the last words. No network, no randomness,
no input — the same line on every run.

Run it with Node 22:

```sh
node main.ts
```
